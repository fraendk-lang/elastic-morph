# Scene Banks 4→16 Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand Elastic Morph's Scene Bank from 4 slots (A–D) to 16 slots (A–P, two toggleable 8-slot banks) plus a separate reserved Basis-Szene slot, with matching keyboard shortcuts.

**Architecture:** Single-file app (`elastic-morph.html`) — all changes are in-place edits to the existing inline `<script>`/`<style>` blocks and `test.js`. No new files, no build-step changes. The live scene-bank logic runs through the v71 patch layer (`patchSceneBank()`), not the original dead block at `elastic-morph.html:8495-8524` — every task below edits the patch layer.

**Tech Stack:** Vanilla JS, `localStorage`, zero-dependency Node test harness (`test.js`, static source-string assertions — see existing pattern at `test.js:36-115`).

## Global Constraints

- Storage stays index-based (`0..15`) under the existing `SCENES_LS = "elasticMorph.scenes"` key — do not introduce string keys for A–P, and do not migrate existing saved scenes (indices `0..3` already land correctly in Bank 1).
- Basis Szene is a separate `localStorage` key (`elasticMorph.sceneBasis`), never a 17th array index.
- Cue/Set-Editor scene dropdown (`elastic-morph.html:8671`) is out of scope — do not touch it. `cue.scene` values `0..3` must keep working unmodified.
- Every new/changed function must keep the existing quota-guard + `showAppToast` pattern used by `saveScene` (see `elastic-morph.html:11000-11022`).
- No Creator-mode exclusion for scene/bank shortcuts (per the approved spec) — only the modal-open (`aria-hidden`) guard.
- Reference spec: `docs/superpowers/specs/2026-08-20-scene-banks-16-expansion-design.md`.

```js
const SCENE_BASIS_LS = "elasticMorph.sceneBasis";

function loadBasisScene() {
  try { return JSON.parse(localStorage.getItem(SCENE_BASIS_LS)); } catch (e) { return null; }
}

function saveBasisScene() {
  const snap = sceneSnapshot();
  try {
    localStorage.setItem(SCENE_BASIS_LS, JSON.stringify(snap));
    showAppToast("Basis Szene gespeichert.", 2800);
  } catch (e) {
    try {
      if (snap.image) snap.image.src = null;
      if (snap.image2) snap.image2.src = null;
      localStorage.setItem(SCENE_BASIS_LS, JSON.stringify(snap));
      showAppToast("Basis Szene gespeichert (ohne Bilddaten — Speicherlimit).", 5200);
    } catch (e2) {
      console.error("Basis scene save failed:", e2);
      showAppToast("Basis Szene konnte nicht gespeichert werden — localStorage voll?", 6000);
    }
  }
  renderScenes();
}

function recallBasisScene() {
  const snap = loadBasisScene();
  if (snap) applyProject(snap, true);
}
```
