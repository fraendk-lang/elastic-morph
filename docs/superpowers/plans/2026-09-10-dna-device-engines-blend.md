# DNA Device-Engine Blend Consistency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The "device panel" DNA 2D engines (EQ, Sequencer, Radio Tuner, VU Wall, Patchbay, Tape, Vinyl, Cassette, Waveform Monitor) currently force `globalCompositeOperation = "source-over"` and draw an opaque chassis, so they always sit as a solid box in the foreground and ignore the existing **DNA Blend** control (`S.dnaBlend`) that every other engine respects. Make these engines honour `S.dnaBlend` like the rest — a pure consistency fix, no new control.

**Architecture:** In each of the 9 engine draw functions, the single `ctx.globalCompositeOperation = "source-over";` line that immediately follows the function's outermost `ctx.save()` becomes `ctx.globalCompositeOperation = S.dnaBlend || "screen";`. Every engine already wraps its whole body in `ctx.save()`/`ctx.restore()`, so nothing leaks. Internal mid-function compositing (`"lighter"` for glowing meters, etc.) is untouched. `drawDance` is deliberately excluded — it is a full-scene effect, not a device panel, and its `source-over` uses are per-element choices.

**Tech Stack:** Single-file vanilla JS app (`elastic-morph.html`), partly regenerated by `node build.js` from `src/inject-vNN.js`, zero-dependency static-assertion test harness (`test.js`).

## Global Constraints

- Only the ONE top-of-function `source-over` line (the one right after the outermost `ctx.save()`) changes per engine. Any other `source-over` inside a function body stays exactly as-is.
- `drawDance` is NOT touched.
- The replacement is exactly `ctx.globalCompositeOperation = S.dnaBlend || "screen";` (same expression the DNA organism uses at its dispatch site, `elastic-morph.html` ~line 6036).
- `src/inject-v81.js` (Vinyl) and `src/inject-v105.js` (Cassette, Waveform Monitor) are build-injected: edit those files, then `node build.js` before `node test.js`. The other 6 engines are in the static region of `elastic-morph.html` — edit directly.
- No new `S.*` field, no new UI, no change to the existing `#dnaBlend` dropdown or `S.dnaBlend` default (`"screen"`).

    const fn = extractFn(name, src);
    if (!fn) return false;
    const save = fn.indexOf("ctx.save();");
    const adopt = fn.indexOf('ctx.globalCompositeOperation = S.dnaBlend || "screen";');
    // the adopt line must exist and sit right after the first ctx.save()
    if (save < 0 || adopt < 0 || adopt < save) return false;
    // and there must be no forced source-over between that save() and the adopt line
    return !fn.slice(save, adopt).includes('ctx.globalCompositeOperation = "source-over";');
  })());
}

  const fn = extractFn("drawDance");
  return !!fn && fn.includes('ctx.globalCompositeOperation = "source-over";');
})());
